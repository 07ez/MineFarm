# 🌾 MineFarm 시스템 기능 기획서 (System Specification)

> **버전**: v1.1  
> **기반 환경**: Paper API (26.3) / Java 25 / PlaceholderAPI  
> **저장소**: [MineFarm GitHub](https://github.com/07ez/MineFarm.git)  

---

## 1. 개요 및 핵심 플레이 루프

기존의 직업(Job) 시스템을 폐기하고, **[자원 채집 → 가공/판매 → 도감 등록 & 토지 확장 및 퀘스트 달성]**으로 이어지는 직관적이고 몰입감 있는 마인팜 본연의 루프를 제공합니다.

```
       [ 야생 월드 ]                           [ 마을 월드 ]
 채광 / 벌목 / 낚시 / 자원 채집  ───────┐         ┌───> 안전한 농사 & 건축
           │                           │         │
           ▼                           ▼         │
      아이템 획득  ───> 상점 판매 (화폐 획득) ───┼───> 토지(청크) 구매 및 확장
           │                           │         │
           ├─────────> 도감 등록 (20개 달성) ────┴───> ★ 첫 청크 구매권 지급!
           ▼                           
   요리 / 가공 제작 <───> 퀘스트 달성 (메인 스토리퀘 & NPC 서브퀘)
```

---

## 2. 월드 구조 (World Architecture)

서버는 상호 보완적인 2가지 월드로 분리 운영됩니다.

| 구분 | 마을 월드 (Town World) | 야생 월드 (Wilderness World) |
| :--- | :--- | :--- |
| **목적** | 개인 거주지 건축, 안전한 농사, 상점 거래 | 채광, 벌목, 낚시, 몬스터 사냥 등 자원 파밍 |
| **청크 등록(땅 소유)** | **가능 (유일한 등록 가능 구역)** | **불가 (청크 등록 제한)** |
| **보호 시스템** | 비소유 땅 상호작용/파괴 차단, 도난 완벽 방지 | 보호 없음 (자유로운 채굴 및 파괴 가능) |
| **농사(Crops)** | 안전하게 보호받으며 대규모 농사 가능 | 농사 가능하나 **서리(약탈/도난) 위험 존재** |
| **채광 / 벌목 / 낚시** | 개인 땅 내 광물 생성 제한, 공용 파밍 공간 없음 | 야생 필드에서 자유롭게 채집 |

## 3. 토지 / 집 시스템 (House & Land Protection)

- **첫 땅 획득**:
  - 시작부터 땅을 지급하지 않고, **도감 20종 등록/완성 시 '청크 구매권' 1회 지급**.
  - 마을 월드의 원하는 빈 청크 위치에서 자유롭게 첫 청크 등록.
- **땅 확장**:
  - 첫 청크 이후의 추가 청크는 **게임 내 화폐(돈)를 지불**하여 추가 등록/확장.
- **보호 및 권한 (`HouseProtector`)**:
  - 비권한 플레이어의 블록 설치, 파괴, 상자/화로 등 상호작용 차단.
  - 경작지 짓밟기(점프) 방지.
  - 유체(물/용암) 흐름에 의한 훼손, 피스톤 밀기, 화재 번짐 등 악용 방지.
  - 멤버 관리: 현재는 명령어(`/house member add/remove <플레이어>`) 지원, 추후 **GUI 인터페이스로 발전 예정**.

---

## 4. 화폐 및 경제 시스템 (Economy)

- **잔액 관리 (`MoneyManager`)**:
  - UUID 단위 플레이어 잔액 데이터 관리 (`ConcurrentHashMap` 기반 실시간 처리).
  - 차감 시 음수 잔액(대출) 방지 및 안전한 트랜잭션.
- **명령어 및 연동**:
  - 관리자/유저 명령어: `/money`, `/balance`
  - PlaceholderAPI 연동: `%minefarm_money%` 등으로 스코어보드/채팅 탭 출력 지원.

## 5. 상점 시스템 (Shop & Display Interaction)

플레이어의 편의성을 극대화하기 위해 **빠른 거래(시선 감지 디스플레이)**와 **GUI 상점(NPC)**의 2가지 경로를 지원합니다.

### 5.1 시선 감지 디스플레이 빠른 거래 (Raytrace Display)
- 블록/아이템 디스플레이에 5블록 이내로 시선을 맞출 시:
  - 타깃 디스플레이에 **발광(Glowing)** 효과 활성화.
  - 상단에 구매/판매 단가를 안내하는 `TextDisplay` 오버레이 팝업.
- **인터랙션 조작 방식**:
  - **좌클릭**: 1개 구매
  - **Shift + 좌클릭**: 64개(1세트) 구매 (잔액 부족 시 보유 금액 내 최대 수량 구매)
  - **우클릭**: 1개 판매
  - **Shift + 우클릭**: 인벤토리 내 해당 품목 전부 판매 (일괄 판매)

### 5.2 NPC 통합 상점 GUI
- 마을에 배치된 상인 NPC 우클릭 시 오픈.
- 카테고리별(농작물, 생선, 광물, 목재, 요리, 특수 소모품) 인벤토리 GUI 제공.

- **화폐 소비처**:
  - 토지(청크) 추가 확장
  - 도구/장비 및 농사·요리 재료 구매
  - **치장(Cosmetics) 및 펫(Pets) 시스템** (엔드 콘텐츠 및 꾸미기 요소)

## 6. 퀘스트 & 메뉴 시스템 (Quest & GUI Menu)

- **메뉴 열기**:
  - **웅크리기(Shift) + F키 (스왑 핸드)** 조작을 통해 메인 메뉴 GUI 오픈.

- **도감 시스템 연계**:
  - 자원 / 물고기 / 작물 / 요리 도감 등록 기능
  - **도감 20종 등록 시 첫 청크 구매권 지급!**

- **퀘스트 진행 구조**:
  - **서브 퀘스트**: 마을 주민/상인 NPC들의 일상적인 의뢰와 편의 보상 제공.
  - **메인 퀘스트 (시즌 1 스토리: 「오만의 대가」)**:
    - *플레이어의 신분*: 연구원이 아닌 외지인/협력자로서, 연구실이 제시하는 채집·납품 과제를 도와주는 역할.
    
    ```
    [ 1막: 평화로운 마을과 연구실 과제 보조 ]
    마을에 놀러온 플레이어가 정착하며, 연구실의 기초 생태계 조사 및 자원 납품 과제를 도와줌.
             │
             ▼
    [ 2막: 금단의 과제 - '불사의 몸(슈퍼 인체)' 연구 지원 ]
    연구소가 심해 생물과 특수 작물 유전자로 '불사의 몸'을 연구하기 시작하여 위험한 재료 조달 요청.
    실험 실패로 기괴한 변이체가 탄생하자, 연구소는 이를 비밀 지하 격리 구역에 봉인.
             │
             ▼
    [ 3막: 새로운 희망과 '완전한 백신'의 단서 ]
    연구 방향을 전환하여 다른 과제를 수행하던 중, 실패를 되돌릴 '궁극의 백신' 단서 발견.
    연구소의 다급한 요청으로 최고난도 희귀 재료(전설의 물고기, 희귀 추출물)를 납품.
             │
             ▼
    [ 4막: 대실패와 샘플 폭주 (시즌 1 엔딩) ]
    완성된 백신 투여 중 유전자 샘플이 폭주하여 마을 전체로 에어로졸/식수원 역감염!
    연구원들과 마을 주민들, 그리고 플레이어 본인마저 바이러스에 감염되는 충격의 엔딩.
             │
             ▼
    [ 에필로그: 감염된 채 살아가는 일상 ]
    자신도 감염되었지만 어떻게든 의식을 유지한 채 팜 생활을 이어감.
    화면에 ❝ To be continued in Season 2... ❞ 연출과 함께 지속적인 마인팜 플레이 지원!
    (돈을 모아 치장, 펫을 구매하며 시즌 2를 대비)
    ```

## 7. 채집 & 커스텀 아이템 & 요리 시스템

### 7.1 낚시 시스템 (`FishManager`, `FishingListener`)
- 50종 이상의 커스텀 물고기 데이터 구축 완료.
- **등장 조건 세분화**:
  - **바이옴**: 바다(Ocean), 강(River), 호수(Lake), 사막(Desert), 동굴(Cave), 빙하(Ice)
  - **날씨**: 맑음(Clear), 비(Rain), 무관(Any)
  - **시간대**: 낮, 밤, 특정 틱 시간대 한정
- **[출시 전 구현 필수 확인 항목]**:
  - ⚠️ **쓰레기 시스템**: 물고기 등장 조건에 맞지 않는 'Other' 영역에서는 쓰레기 아이템 낚시 판정.
  - ⚠️ **용암 낚시**: '용암장어'는 일반 물이 아닌 용암에서 낚시할 때만 출현하도록 구현.

### 7.2 커스텀 요리 & 조합법 (`AddRecipe`, `RecipeUntil`, `CreateItem`)
- 커스텀 모델 데이터(CustomModelData)가 적용된 고유 요리 아이템 (생선구이, 회, 샐러드, 김밥, 버거 등).
- **[출시 전 구현 필수 확인 항목]**:
  - ⚠️ **요리별 고유 버프 및 포만감/영양가 시스템**: 현재 기본 사과 데이터 형태에서 요리별 고유 버프 효과 및 포만감 적용.

### 7.3 농사 시스템 (`CropsManager`, `CropData`, `CropListener`)
- **실시간 시간 기반 성장**: `현재시간 - (심은시간 + 자라는시간)` 기준 판정.
- **청크 로딩 동기화**: 청크 로딩 시 경과 시간을 계산하여 블록의 성장 단계(Age)를 즉시 동기화.
- **웅크리기 + 우클릭 시 실시간 TextDisplay 표시**:
  - 완전히 다 자랐을 시: `수확가능!`
  - 자라는 중일 시: 남은 시간을 `00:00:00` (시:분:초) 형태로 표시.
  - 플레이어의 크로스헤어가 작물에서 벗어나면 `TextDisplay` 자동 제거.
  - 경과 시간에 따른 나이 단계(Age) 동기화 반영.

## 8. 데이터 관리 및 영속화 (Persistence)

- **저장 위치**:
  - `playerData.yml`: 플레이어 UUID, 잔액, 청크 키 목록, 통계 기록, 퀘스트/도감 데이터
  - `cropsData.yml`: 실시간 작물 위치, 심은 시각, 성장 필요 시간, 부스트 계수
- 서버 종료 및 주기적 세이브 시 무결성 보장.
